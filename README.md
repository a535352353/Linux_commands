1.0.3 常用快捷键
## 常用快捷键
功能  
ctrl + c  停止进程  
ctrl+l  清屏；彻底清屏是：reset  
ctrl + q  退出  
善于用tab键  
提示(更重要的是可以防止敲错)  
上下键  
查找执行过的命令  
ctrl +alt  linux和Windows之间切换
